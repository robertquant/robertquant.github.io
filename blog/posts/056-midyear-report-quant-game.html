二、量化框架：中报窗口的三层筛选体系

基于近三个月的研究积累（随笔#053至#055），我将中报窗口期的量化应对提炼为三层筛选体系：

第一层：行业分化度指数（IDF）——判断战场状态

在随笔#055中，我提出了行业分化度因子（Industry Divergence Factor）：

IDF = 行业内个股涨幅标准差 / 全市场个股涨幅标准差

IDF区间市场状态策略响应
IDF < 1.0低分化，普涨/普跌传统动量/均值回归有效
1.0 ≤ IDF < 2.0中等分化，结构性行情行业ETF轮动 + 龙头动量
IDF ≥ 2.0极端分化，微观结构主导产业链分层 + 业绩验证链

2026年H1，光模块行业IDF ≈ 3.2，半导体设备IDF ≈ 2.8——均处于极端分化态。这意味着：

  • 传统动量策略失效（#055回测：IDF≥2.0时月均超额 -1.2%）
  • 微观结构策略有效（同条件下月均超额 +4.7%）

四、风险警示：中报季的三个陷阱

陷阱一：净利润增速的"基数幻觉"

奥来德H1扣非净利润 +2366%，听着惊人，但需要确认：

  • 去年同期基数是否极低？
  • 增长是否来自一次性收益（政府补贴/资产处置）？
  • 扣非后环比趋势如何？

量化规则：增速>500%的标的，必须同时满足"扣非增速>300%"+"环比Q1加速"才纳入观察池。

陷阱二："预期你的预期"的博弈

中际旭创H1净利润+69%——数字很好，但如果市场已经price in了+80%的预期呢？

7月24日数据：中际旭创 +1.10%（光模块板块暴跌中逆势涨），说明+69%的增速已被充分预期。真正超预期的是那些增速低于预期但市场过度悲观的标的——这需要舆情分析+卖方预期数据的交叉验证。

陷阱三：拥挤度的尾部风险

公募Q2电子持仓43.4%，创下历史新高。历史上，单一行业持仓超过40%后的6个月内：

  • 2007年Q2 金融地产持仓45% → 6个月后-35%
  • 2015年Q2 TMT持仓42% → 6个月后-45%
  • 2021年Q2 新能源持仓41% → 6个月后-30%

统计规律不是因果，但拥挤度是必要条件。当前科技股的拥挤度，意味着任何低于预期的中报都可能触发踩踏。

六、结语：数据不说谎，但解读需要谨慎

中报窗口期，每一个数字背后都是一场博弈。量化研究的价值，不是预测哪个数字会超预期，而是建立一个系统化的响应框架——当数据出来时，你知道该做什么。
